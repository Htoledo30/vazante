# Vazante — A Cidade sob a Maré

RPG tático roguelite para iPhone, desenvolvido na pasta CLAUDE.

**Jogar:** https://htoledo30.github.io/vazante/

Abra no Safari. Para instalar, use Compartilhar → Adicionar à Tela de Início.

## Desenvolvimento

`npm run dev` inicia o jogo localmente. `npm run build` gera `dist/` e o cache offline.

Um push para `main` publica automaticamente o jogo no GitHub Pages.
